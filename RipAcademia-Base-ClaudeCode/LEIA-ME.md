# RIP Academia — pacote completo para Claude Code

Este pacote reúne o prompt de implementação do site, 22 fotografias tratadas, uma arte antiga tratada, a logo original e as novas referências de identidade e conteúdo. Todos os 27 arquivos do primeiro envio continuam preservados; quatro deles são cópias idênticas. As cinco referências adicionais estão em uma pasta própria, sem alterações.

**Revisão de animação:** Ribbon Glow foi selecionado como fundo discreto do hero, com uma única instância e adaptações de responsividade, desempenho e acessibilidade. Os dois códigos recebidos estão em `animacoes/`; leia a seção 7.1 do prompt antes de integrá-los. Os arquivos TSX são referências originais, não componentes já adaptados ou testados neste pacote.

## Como iniciar

1. Extraia o ZIP dentro da pasta do projeto e abra o projeto no Claude Code.
2. Peça ao Claude para ler `PROMPT-CLAUDE-CODE-RIP-ACADEMIA.md` por inteiro, depois `CATALOGO.md` e `CONFIGURACAO-NEGOCIO.json`.
3. Use o prompt completo como instrução de implementação. `INICIO-PARA-CLAUDE-CODE.txt` contém uma mensagem curta para iniciar essa leitura.
4. As fotos para o site estão em `imagens-tratadas/`; a logo está em `marca/logo-rip-original.jpeg`.

## Conteúdo do pacote

- `PROMPT-CLAUDE-CODE-RIP-ACADEMIA.md`: instrução completa de criação, conversão, design e implementação.
- `PROMPT-EDICAO-RIP-ACADEMIA.md`: modelos de pedido para editar o site depois de pronto (horários, fotos, analytics, domínio, animação).
- `animacoes/`: códigos Originkit fornecidos pelo usuário e comparação; Ribbon Glow é a opção selecionada, Predictive Arc Horizon é alternativa desativada.
- `CONFIGURACAO-NEGOCIO.json`: conteúdo comercial inicial centralizado e identificação das fontes.
- `marca/logo-rip-original.jpeg`: cópia fiel da logo enviada.
- `referencias-atualizadas/`: cinco anexos originais de perfil, logo, benefícios e horários.
- `imagens-tratadas/fachada/`: duas vistas externas.
- `imagens-tratadas/ambiente/`: três vistas internas.
- `imagens-tratadas/equipe/`: uma foto de grupo, sem identificação de nomes ou funções.
- `imagens-tratadas/treinos/`: seis fotos de treino e equipamentos.
- `imagens-tratadas/funcional/`: sete fotos de atividades com bola, cones e pesos.
- `imagens-tratadas/conexao/`: três fotos de cumprimentos.
- `imagens-tratadas/informacoes/`: uma arte antiga de horários e contato, com dados desatualizados.
- `originais-referencia/`: todos os 27 arquivos do primeiro envio, sem alterações.
- `CATALOGO.md`, `catalogo.csv` e `catalogo.json`: identificação e descrição dos 23 assets tratados.
- `INICIO-PARA-CLAUDE-CODE.txt`: mensagem curta de início.

## Uso das imagens

As fotografias foram tratadas por IA para melhorar definição, iluminação e cor e remover sobreposições do Instagram. Áreas cobertas foram reconstruídas e pequenos detalhes podem diferir das fontes. Os originais acompanham o material para comparação. Os PNGs tratados estão preservados sem nova compressão com perdas após a geração.

As cinco referências novas são fontes de conteúdo e identidade, não fotografias prontas para a galeria. Evite inserir telas de Instagram no layout. Use a logo original sem redesenhá-la; a arte atualizada de horários deve orientar uma tabela em texto no site.

O prompt completo orienta a criação de versões WebP ou AVIF para a página, seleção das melhores fotos, crops responsivos, fluxo direto para WhatsApp, dados atuais e testes. A logo original é a fonte da informação “Desde 2000”; camisetas reconstruídas não são fonte histórica.
